# Concepto 02 · VECTOR

> **"Cada línea es una fuerza. Nada decorativo."**

## Inspiración estratégica

SpaceX · Rivian · Lucid Motors · Hyundai N · ingeniería automotriz
premium · diagramas vectoriales de física aplicada.

## Idea central

El monograma se construye con **trazos vectoriales precisos** —
cada línea sugiere dirección y momento. La "G" se vuelve una flecha
contenida que abraza un "3" cuyos brazos son **vectores apuntando
hacia adelante**. La marca **se mueve sola** sin animación.

Es la versión "ingeniería en marcha" del logo. Lee instantáneamente
como tecnología aplicada a transporte — el cliente sabe que detrás
hay físicos e ingenieros, no diseñadores gráficos.

## Significado del isotipo

- **Trazos no uniformes**: el espesor de cada vector cambia para
  sugerir aceleración (más grueso = más fuerza)
- **Apertura hacia la derecha**: dirección de marcha, sin
  ambigüedad
- **Cuatro vectores**: los 4 ejes operativos del holding (carga,
  data, talento, capital)
- **Sin elementos cerrados**: nada está "completo" — el sistema
  está en expansión permanente

## Palette

| Token | Hex | Uso |
|---|---|---|
| Carbon | `#101317` | Color de marca, fondos hero |
| Platinum | `#E7E9EC` | Background claro, contenedores |
| Cobalt | `#1F3A8A` | Acento institucional, brand color secundario |
| Volt | `#7DF9A4` | Color de acción / status OK. Un solo verde, muy específico |
| Magma | `#FF4D2E` | Critical / alerta (no botones, solo señales) |

5 colores. La paleta más "techy" de los conceptos — verde Volt y
naranja Magma son señales claras de "esto es plataforma de software".

## Tipografía

- **Marca**: Geist Mono / Roobert / Söhne Breit (de pago) →
  alternativa libre: Space Grotesk Bold
- **UI / dashboards**: Geist Sans / Inter Display
- **Numéricos**: Geist Mono / JetBrains Mono
- **Wordmark del logo**: minúsculas con tracking abierto

## Cuándo elegir Vector

- ✓ G3 Tech (productos SaaS + IA) es el centro de la estrategia
- ✓ Queremos atraer talento senior tech (ingenieros de NVIDIA,
  Tesla, Anduril mexicanos repatriados)
- ✓ La inversión va a venir de fondos VC con tesis en mobility/AI
- ✓ Comunicar que somos la "Rivian de la logística mexicana"

## Cuándo NO elegir Vector

- ✗ Si el comprador principal son fleeteros tradicionales que
  desconfían de "lo demasiado tech"
- ✗ Si Logistics (el carrier) va a representar >70% del revenue
  forever — este look está sesgado hacia tech
- ✗ Si el operador necesita ver "calidez" en el logo
