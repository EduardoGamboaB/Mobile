# Concepto 03 · GRID

> **"La carga es información. La información es ventaja."**

## Inspiración estratégica

NVIDIA · Datadog · Snowflake · Notion · Linear · arquitectura
modernista de Mies van der Rohe · displays de control de tráfico
aéreo.

## Idea central

El monograma se construye sobre una **grid de puntos de 8×8**.
Las letras "G3" no son trazos — son **pixeles agregados** que
revelan las formas. La marca **vibra**: cada punto puede iluminarse
de forma independiente, sugiriendo que detrás hay miles de
señales operativas.

Es el concepto más **moderno y digital** de los 5. Sugiere que G3
es ante todo una empresa que **convierte operación física en data
estructurada**.

## Significado del isotipo

- **Pixel grid**: cada unidad, cada conductor, cada viaje es un
  punto en la cuadrícula
- **Densidad variable**: las áreas más densas son las que
  "están activas" — la marca puede animarse mostrando el pulso real
- **Sistema modular puro**: el mismo grid genera todas las
  submarcas con diferente patrón
- **Color por submarca**: el grid acepta acento cromático sin
  desordenarse (única tipología que permite multi-color sin perder
  coherencia)

## Palette

| Token | Hex | Uso |
|---|---|---|
| Void | `#0A0A0F` | Color base, fondos hero |
| Surface | `#15161D` | Cards, contenedores oscuros |
| Mist | `#F0F1F4` | Fondos claros |
| Iris | `#5B6CFF` | **Color de marca G3**, acento principal |
| Acid | `#C8FF3D` | Status OK / data positiva |
| Crimson | `#FF3B5C` | Critical |
| Amber | `#FFB020` | Warning |

7 colores. La paleta más amplia de los conceptos — porque cada
submarca toma un color del set y se diferencia sin romper el sistema.

## Tipografía

- **Marca**: PP Neue Machina (de pago) → libre: Space Grotesk
  Variable
- **UI**: Inter
- **Data display**: JetBrains Mono / IBM Plex Mono
- **Cuerpo largo**: Inter

## Cuándo elegir Grid

- ✓ G3 Analytics y G3 AI son el corazón estratégico
- ✓ Queremos vender a Chief Data Officers y VPs de operaciones
  tecnológicos
- ✓ Necesitamos diferenciar visualmente los 16 productos sin
  parecer caóticos
- ✓ La marca va a vivir mucho en pantalla (vs cabina)

## Cuándo NO elegir Grid

- ✗ Si el branding físico (tractos, uniformes) es el principal
  punto de contacto
- ✗ Si querer evitar verse "como otra empresa de software" — Grid
  es deliberadamente tech
- ✗ Si la operación de carga pesada es el discurso dominante
