# Guidelines · Uso del sistema visual

Aplica al concepto que se elija como oficial. Las reglas se
respetan independientemente del concepto (Monolith, Vector, Grid,
Forge o Pulse).

## Área de protección

Zona libre alrededor del logo = altura de la letra **G** del propio
logo, en cada lado.

```
   ┌──────────────────────────────────┐
   │                                  │
   │         ┌──────────────┐         │
   │   ⬛    │      G3      │    ⬛   │
   │         │   LOGISTICS  │         │
   │         └──────────────┘         │
   │                                  │
   └──────────────────────────────────┘
   ⬛ = altura de la letra G
```

Ninguna otra marca, foto, texto o gráfico invade esa zona.

## Tamaños mínimos

| Uso | Mínimo |
|---|---|
| Digital (pantalla) | 24 px de alto del monograma |
| Impresión papel | 8 mm de alto |
| Vinil sobre vehículo (vista a 10m) | 30 cm de alto |
| Vinil sobre vehículo (vista a 100m) | 90 cm de alto |
| Bordado en uniforme | 35 mm de alto |
| Favicon | usar variante encapsulada (24 px mínimo) |

## Combinaciones de color permitidas

Según el concepto elegido, sólo se permiten estas combinaciones:

### Logo sobre fondo claro
- Logo en su color base (Obsidian / Carbon / Void / Cast Iron / Ink)
- Fondo: Bone / Platinum / Mist / Bone / Paper

### Logo sobre fondo oscuro
- Logo blanco (Bone / Platinum / Mist / Bone / Paper)
- Fondo: color base oscuro del concepto

### Logo sobre fondo color
- Si el fondo es el color de marca (Iris para Grid, Cobalt para
  Vector, Cat Red para Forge, Electric para Pulse), el logo va
  en blanco
- Sobre cualquier OTRO color de la paleta = revisión con Comité
  de Marca

### Sobre fotografía
- Sólo con **capa de contraste** debajo del logo: rectángulo del
  color base del concepto al 70% de opacidad mínimo

## Lo que está PROHIBIDO

- ❌ Rotar el logo (más allá de su inclinación intrínseca si la tiene)
- ❌ Estirar / aplastar / distorsionar
- ❌ Cambiar el color del monograma a uno no autorizado
- ❌ Agregar sombras, brillos, glow, neón
- ❌ Encerrarlo en formas ajenas al sistema (escudos, círculos,
  banderitas) — excepción: variantes encapsuladas oficiales
  documentadas
- ❌ Usar versiones de versiones anteriores (rebrand histórico) —
  todo legacy se purga
- ❌ Inventar variantes "para esta ocasión" — comunicar al Comité
  de Marca
- ❌ Aplicar efectos de Photoshop / Figma decorativos
- ❌ Co-locar logo G3 al mismo nivel jerárquico que el logo del
  cliente — siempre va segundo en lectura occidental

## Co-branding

Cuando G3 aparece junto a otra marca (cliente, partner):

1. **Logo del cliente / partner siempre primero** (izquierda)
2. **Misma altura óptica**, separados por una línea vertical
   delgada del color del fondo
3. **Separación = altura del logo más alto**
4. Si hay tagline conjunto, va debajo en tipografía neutra del
   sistema G3

## Versiones autorizadas

Sólo existen estas versiones del logo. **Cualquier otra es no
oficial**.

- Monograma a color (oficial principal)
- Monograma monocromo claro (sobre oscuro)
- Monograma monocromo oscuro (sobre claro)
- Wordmark completo por entidad (G3 Logistics, G3 Tech, etc.)
- Variante encapsulada para favicon / app icon (la única con
  contenedor)

No existen versiones:
- Holiday / aniversario / pride / etc.
- Animadas con efectos decorativos (sólo transiciones funcionales
  <300ms permitidas)
- "Para clientes especiales"

## Aprobación de aplicaciones nuevas

Cualquier nueva aplicación física o digital del logo (vehículo
distinto, uniforme nuevo, stand de evento) requiere:

1. Mock vectorial a escala
2. Foto / render de simulación
3. Aprobación por escrito del Comité de Marca
4. Versión final archivada en este repositorio

Sin estos pasos, no se autoriza producción.
