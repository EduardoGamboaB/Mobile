# 02 · Arquitectura de marca

## Modelo

Usamos un modelo **endorsed brand** (marca avalada). Cada entidad
del holding mantiene un nombre propio, pero el aval visual y verbal
de "G3" siempre está presente. Es el equilibrio entre claridad
operativa (cada empresa tiene su mercado) y reconocimiento de grupo
(la confianza se acumula bajo el paraguas G3).

```
                   G3  (marca paraguas)
                    │
   ┌────────────────┼────────────────┬─────────────────┐
   │                │                │                 │
G3 Holding    G3 Logistics      G3 Tech         Fundación G3
(corporativo)  (transporte)      │
                                ┌┴┐
                          G3 Admin · G3 Drive
                          (productos B2B)
```

## Niveles de marca

### Nivel 1 — Marca paraguas: **G3**

Atributos compartidos por todo el grupo. Nadie compra "G3" directamente
— es el sello de pertenencia.

- Logo monograma G3 italic navy con tres líneas diagonales
- Paleta corporativa navy + naranja carretera
- Tipografía de sistema
- Promesa: *"Tu carga, en vivo. Nuestra tecnología, abierta."*

### Nivel 2 — Empresas operativas

Cada una con su nombre completo y su propio territorio comercial:

| Marca | Audiencia | Producto/servicio | Voz dominante |
|---|---|---|---|
| **G3 Holding** | Inversionistas, prensa, regulador | Gobierno corporativo | Institucional |
| **G3 Logistics** | Embarcadores, clientes de carga | Servicio de transporte | Operacional, cercano |
| **G3 Tech** | Otros transportistas, flotas | SaaS G3 Admin + G3 Drive | Técnico, didáctico |
| **Fundación G3** | Operadores, comunidades, ONGs | Capacitación, bienestar | Humano, comunitario |

### Nivel 3 — Productos (sólo dentro de G3 Tech)

| Producto | Categoría | A quién va |
|---|---|---|
| **G3 Admin** | Aplicación web (panel) | Owners, dispatchers, contadores |
| **G3 Drive** | Aplicación móvil (iOS / Android) | Conductores, operadores de patio |

## Reglas de uso del nombre

### Sí

- "G3 Logistics" como nombre completo en primera mención
- "G3" como referencia abreviada en menciones siguientes dentro del
  mismo texto, una vez que el contexto está claro
- "G3 Admin" y "G3 Drive" siempre con el prefijo G3 — nunca solos como
  "Admin" o "Drive" en comunicación externa
- "Fundación G3" con la "F" mayúscula

### No

- "g3" en minúsculas (excepto en URLs y emails: `g3logistics.mx`)
- "G3logistics" sin espacio
- "GTres", "G-3", "G three", "Grupo G3" — solo G3
- Usar el logo del holding cuando se habla específicamente del SaaS
  (ahí va el logo de G3 Tech)

## Co-branding

Cuando G3 aparece junto a otra marca (cliente, partner, integrador):

1. **Prelación visual**: el logo del cliente/partner siempre primero
   (a la izquierda en lectura occidental). G3 acepta el segundo lugar
   en cualquier co-branding — la operación no necesita ego.
2. **Tamaño**: ambos logos al mismo *cap-height* (no por ancho — los
   monogramas se distorsionan).
3. **Separación mínima**: el espacio entre ambos logos = altura del
   logo más alto.
4. **Fondo neutro**: blanco o navy 900. Nunca sobre fotografía sin
   capa de contraste.

## Decisión: cuándo crear una nueva marca

Antes de inventar una submarca nueva, pasar las **3 pruebas**:

1. **Audiencia distinta**: ¿el nuevo producto/servicio se vende a una
   audiencia que NO compra ninguna marca actual?
2. **Modelo de negocio distinto**: ¿la economía (margen, ciclo de
   venta, soporte) no encaja con las existentes?
3. **Riesgo cruzado**: ¿hay un riesgo real de que el éxito o fracaso
   contamine a las marcas hermanas?

Si las 3 son "sí", se crea submarca. Si alguna es "no", se extiende
una marca existente.
