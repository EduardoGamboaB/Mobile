## Pruebas rápidas

Antes de aprobar cualquier pieza de marca, contestar:

1. ¿Usa los tokens canónicos (paleta, tipografía, espaciado)?
2. ¿La voz suena a G3 — concreta, cercana, honesta?
3. ¿La frase de marca o un derivado es identificable?
4. ¿Cumple WCAG AA mínimo en contraste?
5. ¿Funciona también en blanco y negro?

Si alguna respuesta es "no", se devuelve para iteración.
