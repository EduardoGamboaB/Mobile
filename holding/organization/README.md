## Cómo usar este manual

- Es la **fuente única** para preguntas de "¿quién hace qué?" o
  "¿cómo lo hacemos?"
- Cualquier rol o proceso nuevo debe documentarse aquí antes de
  considerarse vigente
- Onboarding de cualquier nuevo empleado incluye lectura de este
  manual como primer día
- Revisión anual completa, actualizaciones puntuales vía PR
